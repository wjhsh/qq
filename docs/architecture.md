# 架构与运行边界

运行链路：QQ 官方客户端 → OneBot 接线层 → QQ Agent → 模型网关或已注册工具。

QQ Agent 保存按聊天区分的消息、角色和记忆，负责真实 @ 判定、白名单、机器人排除、工具权限、撤回及发送队列。普通聊天模型通过配置选择；切模型不切角色。生图提示词由宿主从当前发言提取，模型工具参数不能替换原文或任意挑选历史图片。

任务工具通过只监听本机的 harness 提交工作。Pi 处理工作目录内的任务；维护模式先产生受限源码副本和待审差异，经过宿主确认后才应用。任务受并发、内存、CPU、时限及目录范围约束。源码中已有的风险与未验证能力不等于已具备自动维护闭环。

Chat 图片任务使用单独的图片工作进程，具有输入清单、执行回执、持久化会话指针和图片产物校验。同一聊天、发言者、Chat 账号分别隔离会话；令牌仅在私有部署环境提供。

明确上传参考图时，从同一 Chat 对话的可验证干净根节点分支，让当前参考图和原提示词成为该分支的输入。原对话与旧分支保留。纯文字追问接续当前分支；需要继续改某张图时可明确引用该图。

图片只在原要求与参考消息仍存在、权限仍有效时发送。失败不自动重新生成、不切换提供方；发送回执不明也不重新生成。用户明确要求修正时可单独创建一次有记录的修正任务。

手机管理使用已有私网 HTTPS 入口。仓库未包含私网节点凭证、真实域名、订阅节点或服务器密钥，也没有建立新的公网管理入口。
