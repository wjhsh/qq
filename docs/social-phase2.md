# 第二阶段：有对象、有证据、有知识的社交表达

本轮为开发版本，未部署生产、未替换角色卡或私人记忆。默认 `socialBehavior.phase2.enabled=false`。生产仍是20261030-ded8f08。

## 统一数据流

```text
真实消息/引用/图片元数据
  → 原输入与机器人识别闸门
  → 唯一互动对象（不取批尾）
  → 该群/完整角色版本/对象的衰减状态
  → 可选通用机制 + 已审核本群梗
  → 原本的一次模型回复与工具选择
  → 原发送队列/真实回执/收尾
  → 本轮原文证据校验 → 状态回执 + 有限转折轨迹
```

没有新增逐消息分类调用。假怒、真不满、反串立场仍由本轮推理结合语境判断；确定性代码只保障寻址、证据、角色/群隔离、叫停和预算。不会因为“什么意思”出现两次而猜用户生气，也不以亲近度给嘴臭授权。

## 状态与记忆

`SocialState`沿用version1的愉悦、激活、信心和关系衰减；confidence不是标准PAD的dominance。20分钟/7天等是可实验的工程参数，不能称心理学定律。

开启interactionTrace后，可在已有socialFeedback中附可选outcome：landed、missed、uncertain、comforted、conceded。只存最近3项 `{evidenceId,event,outcome,at}`，20分钟后不参与提示；拒绝/重放事件不刷新轨迹，证据ID被回收时同时移除悬空记录。它是猫对互动的可错评价，不是对方情绪事实或同意。

`MemoryStore`继续保存按会话隔离的群友事实印象，没有在本轮强制迁移成角色库。事实/共同经历可由原工具查询，但临时玩笑、罐头欠条和关系数值不写成事实。角色卡提供稳定偏好与猫耳尾巴，小鱼干等不被删掉；本轮不自动学习永久动机或改写人设。

`session.socialFeedbackStats`只含validated/applied与拒绝原因计数，不含原文、QQ、quote或消息ID。校验通过与状态真更新分开；达到预算仍占用本轮唯一有效候选，不能通过换事件继续试刷。磁盘失败保留原数据并停用社交状态，直接请求仍走保守聊天路径。

## 三种知识范围

|范围|承载|边界|
|---|---|---|
|通用幽默机制|只读 `qq-agent/knowledge/humor-mechanisms-v1.json`，12张原创卡|来自研究分析的综合，不是90条原句的训练导入；审核摘要、来源ID、角色类型、失效日期、反例|
|本群梗|原MemeLibrary|pending→主人明确收藏；完整群/角色版本、过期、禁用、去重与来源规则不变|
|私人经历/群友事实|原记忆工具|不跨群/私聊搬运，不由机制卡捏造；本轮不增加另一个记忆服务|

机制卡提供角度、立场、使用条件和停止条件，不提供固定台词。最多两张，允许完全不用；同角色/会话短期避免连续重复提供同一批卡。这个缓存记录“曾提供”，不冒充模型实际用了某梗。猫自利卡仅给宿主选中的普通猫角色；其他角色仍可用通用结构，不强套猫身份。

词匹配与BM25+小量人工词场在同库、同top-k=2下比较。检索不宣称识别任务或情绪；严肃同词查询仍有误召回，必须由当前任务与反馈压过素材。现有群梗也可用hybrid，但先做scope/审核/版本过滤，不用全局索引抹掉权限。

B站学习继续沿用原只读工具、每天/冷却预算与主人审核。提取器新增可选立场、词场、机制/使用/停止字段，按确切来源窗口验证后保存pending；不增加每条QQ消息调用。原有低频提取调用仍是一次，输出上限从1600到1900 token。贴吧等未来来源应实现同样的来源记录与候选协议，不能让外部评论直接改角色或权限。

## 开关与回滚

非生产实验配置见 `examples/social-phase2-development.json`，不要直接覆盖config.json；只合并审阅后的socialBehavior字段。这是当前profile的全局实验开关，不是已经实现的按群灰度开关。

关闭phase2即可退回原风格段与词匹配，不删除关系或轨迹；单独关闭interactionTrace或humorKnowledge可做消融。对象选取纠错与反馈计数属于基础修复，不依赖phase2。若需要完整源码回滚，v1旧字段与事件枚举保留，旧加载器忽略新增trace字段。

后续经批准发布时，应将新源码及机制JSON作为同一版本资产；事务脚本只为该固定JSON新增白名单，损坏JSON在停服前拒绝，不允许任意配置文件。先保持phase2关闭验证加载，再批准独立测试profile或补充按群开关的灰度。备份源码、现有config与状态；不使用旧的“只上传src”清单漏掉知识文件。回滚保留新生成的私人记忆，遇到冲突拒绝覆盖。

## 研究依据与可验证限制

- [Scherer 2005](https://doi.org/10.1177/0539018405058216)及[评价理论研究著作](https://academic.oup.com/book/53557)提供“评价事件而非堆情绪标签”的启发；本项目的时间参数和字段不是论文验证的心理模拟。论文页面/摘要已核，部分全文访问受限。
- [Sacks、Schegloff、Jefferson 1974原文摘要](https://www.conversationanalysis.org/schegloff-media-archive/simplest-systematics-for-turn-taking-language-1974/)强调局部管理与接收者设计；在QQ异步群聊的实现是工程迁移，需自己的回放。
- [McGraw、Warren 2010](https://pubmed.ncbi.nlm.nih.gov/20587696/)的良性违背假说不能化约成固定好感阈值。共同玩笑、关系与退出条件仍需语境证据。
- [Park等2023](https://research.google/pubs/generative-agents-interactive-simulacra-of-human-behavior/)展示记忆/反思/计划的智能体结构，不证明本项目值得照搬昂贵的完整反思循环。
- [Robertson、Zaragoza 2009](https://doi.org/10.1561/1500000019)是BM25检索设计依据；本实现用短机制卡的二值词频变体，效果以本项目正负例为准。

普通测试只证明规则与接线。多轮模型回放用文本计划、真实宿主工具执行与模拟回执，既不是真实QQ群，也不恢复完整线上上下文；人工盲评仍须用户完成。详细结果和反例见reports/social-phase2-20261030/。
