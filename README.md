## 离线检查

需要 Node.js 20+、Python 3.10+ 和 Pillow。

```sh
cd qq-agent
npm ci --omit=dev --ignore-scripts
cd ..
python -m pip install -r requirements-dev.txt
python tools/check.py
```

检查使用临时目录、模拟网络与示例身份，不需要 QQ 登录、Google/Chat 凭证或真实群聊。Linux 生产任务隔离另外依赖 systemd；这组回归不会启动真实模型任务。

## 部署边界

这是源码维护基线，不包含一键重建全部服务器的安装器。QQ 官方客户端及 OneBot 接线层、Pi/Codex 可执行文件、模型授权、私网身份和 systemd 配置须在部署环境中独立管理。

QQ Agent 本身的依赖记录在 `qq-agent/package.json` 及锁文件。运行前按 [配置说明](docs/configuration.md) 在私有数据目录准备配置；不要把真实配置复制进 Git。

参见 [架构与运行边界](docs/architecture.md)、[角色卡位置](docs/role-cards.md) 和 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 隐私

不保存账号凭证、真实账号号码、私聊对话、私聊记忆、生成图片、带签名的媒体地址或任务工作目录。源码中的部署示例标识已替换为虚构值；源码清单记录了这些转换。

`analysis/` 是管理员另外明确授权公开的群聊与角色分析快照，保留清理后的群聊原句、群记忆及实际保存角色卡；具体范围和限制以各次资料说明为准。分析快照不会自动应用回线上配置，原始存储仍由服务器保管。
